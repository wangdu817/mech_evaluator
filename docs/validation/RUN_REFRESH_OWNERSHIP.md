# 刷新后的运行任务恢复

截图中的问题来自 Streamlit 新会话丢失 `worker` 引用：后台线程继续运行，但启动按钮只检查会话内引用。重复启动被结果目录的独占 `run.lock` 拦截，已有写入任务没有被覆盖。

修复后，运行页面同时检查磁盘锁的 PID/线程存活情况，重新连接同进程的后台线程；其他进程或尚无法解析的锁阻止重复启动。取消支持持久化 `CANCEL` 请求，不依赖丢失的会话事件。实时状态在任务终止后刷新整页恢复按钮；遗留 running 进度不会被误称为仍在运行。单工况分析也检查批量运行锁。

测试：`tests/test_run_ownership.py` 验证新会话重连、无事件取消、外部进程、未知锁、死线程及按钮状态；与结果快照和分析布局回归合计 12 项通过。测试未删除生产锁和计算结果。安装包另经模块导入检查。

本轮部署通过 `tools/restart_idle_ui.py` 安全检查后更新 8502 服务；该脚本只允许无运行任务时重启。本轮未完成真实浏览器刷新交互验收，按钮行为通过 Streamlit AppTest 验证。
