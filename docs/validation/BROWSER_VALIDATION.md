# 真实网页功能校验与修复报告

本报告保留首阶段示例流程校验。后续已使用用户提供的实际甲胺 YAML 与全部 37 XML 完成计算及网页后处理验证，成果、失败与绘图约定见 `ACTUAL_VALIDATION.md`。

校验日期：2026-10-08。通过实际浏览器操作本机 Streamlit 服务
`http://127.0.0.1:8501`，完成配置生成、上传、预检查、计算、取消、恢复、重试、评分、绘图与下载。
这是本地真实网页端到端校验；不代表已部署远程生产服务，也不代表甲胺机理的实验预测已验证。

## 发现并修复的问题

1. 后台任务结束后运行/取消按钮状态未刷新。现在完成或失败事件触发整页刷新；取消后可直接恢复。
2. 代码热更新期间提交求解函数出现序列化错误。使用独立进程入口并动态取得当前模块入口；网页重试后原批次全部通过。
3. 修改配置后仍可沿用旧检查状态。现在运行按钮要求当前配置已预检查；检查结果在页面交互后保留。
4. 上传相对路径配置缺少路径基准。增加基准目录输入，导入时转换成完整路径。
5. 保存/下载原始相对路径配置后，文件移到其他目录不能直接供命令行使用。现在保存和下载解析后的完整路径配置，下载文件在结果目录内重新读取验证通过。
6. 重新载入时评分、单位和绘图布局未恢复。现在恢复独立保存的 scoring.yaml 和 figure.yaml，并重置对应控件。
7. 取消选择曲线后旧图仍留在页面及导出目录。现在成功重绘后仅清除上一轮清单追踪的过期图文件，保留用户自有文件。
8. 新任务可能继续显示上次载入的结果。启动批次时清除旧的结果快照；增加“重试失败工况（保留成功缓存）”控件。

## 本地甲胺机理的实际阻塞

检查了机理优化/mech 下的 `26092002_整理版.inp` 和 `mech.inp`，配套使用
CH3NH2/MECH/thermo.dat，传输文件为机理优化/mech/trans.dat。
严格转换失败，网页清楚报告错误并阻止启动：

- 整理版：重复声明 CH3NHNH2；REACTIONS 行包含不支持的 MAXSP=8；PLOG 数值 +1.990+50 等不符合解析语法。
- mech.inp：重复声明 CH3NCO；部分反应参数 0.00E 不完整；也包含上述 PLOG 格式错误。
- thermo.dat：两处 NASA7 区段无法严格解析。
- trans.dat：NCNOH 数据重复，多个整理版物种缺少传输参数。

未自动启用 permissive、删物种、修改动力学参数或补传输参数，遵守 SPEC 的机理输入约束。
因此本轮没有取得这两份甲胺机理的四类实验预测或正式排名。
转换日志分别保存在 results/browser-e2e/mechanism、mechanism-base 及 methylamine/prepared。
