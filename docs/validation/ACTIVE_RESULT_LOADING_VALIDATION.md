# 运行中结果载入修复与验收（2026-10-10）

## 原因与修复

- 普通“载入结果”、批次合并和恢复原先直接调用 `load_run`，主动拒绝运行中的目录，只有任务页专用按钮会创建快照。增加共享 `result_access.load_result_view`：运行中自动载入已提交的结果视图，保留底层运行目录的写入保护。
- 结果载入会改变结果目录控件的值，快照路径与输入路径不同时可能触发 Streamlit 控件实例化后的赋值异常。目录控件值改为下一次刷新前应用；运行中的原目录保留为刷新来源。
- 任务页快照入口可使用配置中的输出目录，不再依赖浏览器会话必须亲自启动过任务。普通载入入口运行中可用。
- 已有结果合并、恢复与单工况分析载入复用同一访问规则。部分结果可做诊断评分与绘图；正式排名条件保持不变。
- 快照沿用每批次一个 view，完整 HDF5 使用同卷硬链接，不额外复制全部历程，也不修改原批次锁和模拟结果。
