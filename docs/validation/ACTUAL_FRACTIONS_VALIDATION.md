# 实际摩尔分数修订（2026-10-09）

按用户最新要求覆盖 v1 原浓度归一化要求：移除运行配置与界面中的干湿选择、确认限制、评分排除及除水换算。组分预测直接提取反应器 mole_fractions，物质的量浓度仍使用 concentrations，不改变入口水或其他 XML 条件。

旧配置可载入，相关字段会被忽略。原历史文件保留；曾转换过的预测在载入时从同一工况 HDF5 末状态恢复实际值，保留原预测的审计记录。无法核对历程的记录标为 unverified，不能继续冒充成功预测。旧受阻工况仍是未计算，需重新运行。

数值语义发生改变，未把新引擎指纹映射到旧缓存键。旧历史可以离线载入比较，新增工况使用新键，避免误用先前转换值。

实际验证：读取 audited 历史 exp5 结果，逐目标核对恢复值等于 HDF5 原始实际摩尔分数，历程哈希不变；用 clear 机理预检查 Marrodan Set4/Set5，原浓度限制消失；独立求解一个原受阻真实工况，success，全部物种预测与保存的实际末态摩尔分数相等。具体工况、参数和结果见 results/actual-fractions-validation.json。

旧验收报告反映旧版行为，不能用其中的基准待确认、排名覆盖率和转换预测作为修订后验收结果。
