# 运行机理选择与自动跳过

新增运行页“本次运行机理”多选；默认包含配置中的全部机理，用户可以仅选一个。选择参与预检查身份，改变选择后阻止直接启动，要求重新预检查；预检查及实际提交配置均只含选中机理。空选择不能启动。

已有成功且通过验证的缓存自动跳过，检查身份、观测值及历程存在。其他结果目录可以由界面填写，严格按完整缓存身份复用；旧版本缓存身份不符不能自动冒用，但可以直接载入历史结果绘图。当前目录不会作为其他目录重复读取。

运行记录新增 cache_hits 和 submitted_cases，进度页显示跳过/新提交数量。旧批次没有计数时明确显示未记录。重试失败勾选不使成功工况重算；未点火、失败及未验证的结果不冒充成功。

实际证据：clear_26092002 + 原 Hjuler_1995_Set13.xml，12 个成功工况先从此前真实目录跨目录复用，再从当前目录恢复；两次各 12 个缓存命中，新提交均 0，第二次缓存文件时间戳不变。证据 results/run-selection-cache/verification.json。原始结果目录不覆盖。

页面测试验证从两个机理选一个、仅预检查一个、空选择阻止启动、重新选择需要预检查，并回归评分和绘图。实际浏览器确认机理可单选，其他机理仍在配置中；截图 results/run-selection-cache/browser-run-selection.png。

缓存条件：XML、机理及配套数据、气相、物种映射、物理工况、模型、求解/验证参数及计算实现版本一致；评分、绘图及输出目录不影响模拟身份。更改上述物理或数值条件会重算。跨目录复用及历史比较需保留原 HDF5 历程目录。
