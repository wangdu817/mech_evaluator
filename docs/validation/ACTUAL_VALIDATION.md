## 数值验证与实验误差

独立 Cantera 参考脚本直接读取原机理和 XML 条件，不调用项目求解器。抽样 PFR、950 K JSR、压力导数最大值点火定义对照均低于 1%：最大相对差分别为 4.84e-8、2.66e-8、1.67e-4。另一个 1011 K JSR 独立计算在 100τ 内也未达到稳态；没有以扩大阈值伪造成功。这些为参考工况验证，不表示每个实验预测准确，也不构成实际火焰求解验收。

已明确干基的 exp5 NRMSE：Set13 的 CO2/CO/NO 为 9.70%/20.63%/7.13%；Set14 的 NO/NO2/N2O/CO/CO2 为 9.80%/25.35%/27.18%/34.77%/8.88%。这些是原始实验工况直接求解后的曲线误差。

测量状态为：216 个可正式评分，5296 个测量基准待确认，56 个受 JSR 失败影响，9 个火焰输入不完整。因此正式总榜不合格。3.873% 的评分测量覆盖率与 97.95% 的数值工况成功率口径不同。成功部分诊断组合分 14.98365（点火 E 与 exp5 NRMSE² 等权），不能作为全库正式排名。

## 网页后处理与绘图验收

在 http://127.0.0.1:8501 实际操作完成：载入结果、分类与失败汇总、重新评分、数据集选择、指定曲线模式开关、percent/ppm 单位切换、保存重绘、PNG/PDF/SVG 导出及 ZIP 下载。运行完成后停止定时刷新，避免干扰后处理选择。

选择 8 个数据集后，默认加入全部 17 条测量曲线，输出 exp5 Set13 三物种子图、Marrodan Set1 五物种子图（多仪器共用子图）、六个 MIX 的点火合图。不需要逐一选择物种。

模拟仅绘制线；实验仅绘制点及已有误差条。宏观参数合图中同一条件的实验点与模拟线同色，不同条件用颜色区分，多机理用线型区分。刻度朝内、四边框封闭；exp4 的 1.3 atm 标注 estimated。失败点与未验证点断开模拟线，零值保留。未确认出口测量基准的组分图明确标注湿基预测待确认。

图形对象审计确认六组实验点和模拟线颜色逐组相同，内向刻度和四边框生效。实际下载 ZIP 的 23 个文件可读，含 5577 条对应记录、18 条失败记录、3 组 PNG 300 dpi/PDF/SVG。重评分及重绘前后模拟缓存文件及修改时间完全一致。

97 项测试通过；Streamlit 页面测试无异常；实际数据数值与导出审计通过。wheel/sdist 构建与包含模块检查通过。本次实际科学运行只有一个甲胺机理；未将同一机理复制后冒称不同机理对比，也未以示例机理代替实际机理。
