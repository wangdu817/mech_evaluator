物理和参考测试分别使用独立的 Cantera 计算：

- PFR 与更紧容差的定压参考对照；无反应物种守恒；不可逆一阶反应满足 `X_A=X_A0 exp(-kτ)`。
- JSR 与 `advance_to_steady_state` 独立参考对照；无反应入口守恒；一阶反应满足 `X_A=X_A0/(1+kτ)`，证明采用开放稳态模型。
- 点火用高分辨率等间隔压力历程独立提取最大压力梯度，延迟差异小于 0.5%。
- 火焰用独立 0.12 m 域、较细网格参考，速度差异小于 1%；每个批量火焰还执行网格加密与域宽扩大验证。
- 默认反应器容差 `rtol=1e-9 / atol=1e-15`，验证收紧十倍；相对判据 1%，近零绝对判据 `1e-10`。实际参数和差异保存在每工况 JSON/HDF5 中。

因此本报告没有甲胺机理实验误差结论。不能把成功加载、求解器收敛或软件测试通过称作机理实验验证通过。

## 环境与已知限制

本机验证环境为 Python 3.13.3、Cantera 3.2.0、Streamlit 1.65.0，主要依赖版本见 `results/runtime.json`。
`.venv313` 复用本机既有科学计算库，补充依赖均安装到项目环境；全局其他工具的依赖冲突不属于该依赖核对范围。
本次完成了项目内安装和 wheel 导入检查，未声称在另一台全新 Windows 机器上完成全量环境复现。
干净环境安装脚本为 `setup.ps1`，启动脚本为 `start.ps1`。

- v1 不写 XML、不导出 Excel，不新增自动优化、敏感性或路径分析，也不新增非理想反应器模型。
- 中文路径的自包含机理与本次 CHEMKIN 流程已验证；包含复杂外部 YAML 引用时仍受 Cantera 引用解析能力约束，加载失败会明确报告。
- 干基摩尔浓度（mol/m³）需要额外物理定义；通用摩尔分数干基转换只采用 `X_i/(1-X_H2O)`。
- 图中的零值不会为对数轴被改写；对数轴无法显示的原始零值仍保留在数据和 CSV 中。
- 初次安装需要取得 Python 依赖。已安装的本机环境运行和后处理无需联网。
- 数值验证是离散检查，不是模型误差证明；机理正式排名还要求所选实验测量全部成功、验证通过且评分尺度完整。
