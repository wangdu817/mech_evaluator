## 修复

- 全部自适应积分步及各物种历程按 256 行分块流式写入 HDF5，避免基础求解和收紧容差验证同时保存完整数组。未删减采样步。
- 工况结束清理 Python 对象，每个进程池累计提交 `workers × 8` 个任务后排空并重建，限制原生求解器内存累积。
- 运行页读取小型 progress.json；完整 manifest 最多每 30 秒更新一次。原 manifest 约 41.67 MiB，不再每秒解析。
- 系统可用内存低于 1 GiB 时请求取消并保留已提交结果。JSR 在每个积分步检查取消。
- 历史页面分别显示已处理、数值验证通过、取消待恢复；启动时缓存复用按成功/其他状态说明。
