# 敏感性图表默认展示验证

原因：全物种敏感性选择原先只展示已导出的 views/<物种>/sensitivity.png；没有点击导出时只出现表格。

修复：切换保存物种或变量后直接读取矩阵，绘制横向正负敏感性条形图；按绝对值排序，提供独立的前 N 条显示设置。近零目标使用绝对导数，不能制造归一化系数。导出沿用同一绘图函数及当前显示数量，保留 CSV/PNG/PDF/SVG。每次预览关闭 matplotlib figure，避免累积。

测试：4 项通过（图表及既有运行区布局）。验证正负值及排序、近零/失败处理、无需点击导出即可出现图、切换物种及显示数量、无新求解或视图文件、无遗留 figure。

实际结果：读取 1073 K 已完成分析的 1881 条反应敏感性，生成 results/sensitivity-chart-validation 内 CSV、PNG、PDF、SVG，没有重新计算。
