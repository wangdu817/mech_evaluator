# 工况分析多选与合图验收

## 界面

保留原“6 单工况分析”页，不添加新页面或新的对比入口。现有 set/mix、变量值、机理、匹配工况、分析物种及历史分析选择均改为多选。单工况保留可选 ROP 位置和点火温度敏感性时刻；多个工况分别采用各自稳态/原着火时刻，PFR 始终积分整个计算域。

## 计算与复用

每次只启动一个独立分析求解进程，按任务顺序处理，避免把多个全反应敏感性矩阵同时放进内存。一个工况的敏感性积分保存全部物种；增加展示物种无需再次积分。多物种 ROP 各自保存。相同分析设置的已完成结果直接复用；取消发送到当前任务并停止后续任务，已完成结果保留。

## 合图

同一完整机理内容身份、同种实验类型、同目标/物种及同单位的不同工况用并列横条。不同机理、物种、单位、ROP 积分方式使用子图。同机理以反应编号对齐并核对方程，保留重复反应；不同机理不会用相同编号自动匹配。排序采用各工况的最大绝对值，不二次缩放原始系数。未保存系数标 ×，CSV 为 not_saved/空值，不能解释为零。

任一工况基准接近零时，该子图统一使用绝对导数。点火温度敏感性标明固定时刻代理。PFR 使用全域积分 ROP，不与瞬时速率合在同一坐标。当前内存保护：每张最多 8 个子图，每子图最多 8 工况；物种最多 4，选中工况最多 32。图片关闭 figure 后释放，导出 PNG 300 dpi / PDF / SVG / CSV / JSON。
