# 统一结果载入入口（2026-10-12）

运行页原“载入 / 刷新已完成结果快照”强制生成快照，即使来源任务已结束；原“载入最近运行批次用于评分与绘图”本身已支持自动判断运行状态。现合并为“载入 / 刷新计算结果”。运行中读取已提交的结果快照，不改变原任务；任务结束、取消或失败后读取保存的批次，保留其状态与缺失工况。再次点击刷新后处理视图，不调用模拟求解器。

载入回执区分完整批次与部分结果。快照说明根据 source_status 判断原任务是否仍在运行，避免对结束后的强制快照误称“原任务继续运行”。命令行显式 snapshot 接口保留。

测试：tests/test_live_snapshot.py 与 tests/test_ui_feedback.py 共 10 passed；涵盖运行中自动读取、无 progress.json 的旧批次、刷新快照保留任务所有者、未完成历史不能作为成功结果，以及同一个加载函数在完成后直接读取完整来源目录。wheel / sdist 构建及 wheel 模块导入检查通过。

正式 8502 服务在确认无计算子进程或运行锁后刷新。未启动新模拟，未删除原结果。
