# 日志清理与一键启动验证

已删除停止服务、旧测试、已完成工况分析和基准测试产生的 56 份日志；另删除本次启动调试留下的 1 份临时日志。释放约 5 MB。保留 6 份工作机理转换/加载审计日志，以及正在运行服务的当前日志。

清理前后逐个核对全部非日志结果文件的路径、大小和修改时间，一致；未删除历程 HDF5、结果 JSON、缓存、图表、CSV、配置和机理 YAML。详细清单见 results/runtime/log-cleanup-*.json。

一键启动.bat 可在 Windows 中文路径下双击。实际使用 Windows PowerShell 5.1 验证：环境检查通过；从无服务状态启动成功，健康检查返回 200 / ok；从项目上级目录运行批处理成功，重复启动复用同一个服务 PID，没有新建第二个计算服务。服务在后台运行，关闭启动窗口不停止计算。

优先使用 .venv313，找不到则使用 .venv；默认端口 8502，优先复用本项目已有服务，其他程序占用端口时选择可用端口。默认自动打开系统浏览器。启动日志和服务地址记录在 results/runtime。没有环境时提示先运行 setup.ps1，不自动下载或安装依赖。

修复了 Windows 虚拟环境 Python 启动器与实际服务进程 PID 不同导致的就绪误判，验证使用已启动进程的子进程树。仅检查本机健康接口，不通过系统 HTTP 代理。
